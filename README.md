# BugSense AI 🚀
AI-powered QA Test Risk Analyzer using Machine Learning + Gemini AI.

## 📌 Overview

BugSense AI helps QA teams identify **high-risk components** and prioritize testing efforts before release.

The system analyzes bug data, predicts risky areas using ML, and generates AI-powered testing recommendations.

# 🔍 Features

-> 📂 Upload bug CSV files
- 🤖 ML-based high-risk bug prediction
- 🧠 Gemini AI testing strategy suggestions
- 📊 Risk-based component analysis
- 📈 Interactive dashboard & charts
- 🎯 Smart QA decision support

# 🛠️ Tech Stack

- Python
- Streamlit
- scikit-learn
- Pandas
- Plotly
- Google Gemini AI

# 🧠 Machine Learning Used

- Random Forest Classifier
- TF-IDF Vectorization

# 📊 Input CSV Format

Your CSV should contain:

| priority | component | summary |
|----------|-----------|----------|
| high | Login | Login button not working |


# 🚀 How to Run

## 1️⃣ Clone Repository

git clone <your-repo-link>
cd BugSense-AI

## 2️⃣ Install Dependencies

pip install -r requirements.txt

## 3️⃣ Run Application

streamlit run app.py

# 🔑 Gemini API Setup
